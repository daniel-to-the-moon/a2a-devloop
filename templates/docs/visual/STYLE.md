# 画面风格目标（视觉验收的评分依据）

视觉验收角色（`scripts/devloop/visual-judge.mjs`）把本文件全文、`docs/visual/reference.png`（可选，用户给的风格参考图）和截图一起交给多模态模型评分。改这里就是改评分标准，需用户确认。
按项目改写下面每一节：写具体的色值、造型语言和光照，越具体，评分越稳定。参考图只借风格，不复刻其中的具体物体、构图或品牌元素。

## 1. 配色（palette）
- 主色调：<例：暖色黄昏，天空灰蓝 #7f93c4 → 地平线杏色 #f3cfa0>
- 主体与背景的对比：<例：主角冷色，背景暖色>
- 避免：<例：大面积高饱和纯色、纯黑阴影>

## 2. 造型（shape）
- <例：低多边形、切面清楚、轮廓简洁可读>
- 结构要交代清楚：部件有支撑和连接，不出现悬空、穿模、跑到主体外的部件；出现任何一处，造型分不高于 3（单测与包围盒查不出这类问题）。

## 3. 光照（lighting）
- <例：低角度暖色阳光、柔和长影、地平线辉光>

## 4. 可读性（readability）
- 主体在画面中清晰可辨，不被雾、阴影或界面遮挡；文字清楚、不重叠。

## 5. 不退步（regression）
- 与 main 上一版截图相比：没有穿模、黑块、闪烁、缺失物体、比例失调等明显退步。

## 评分说明
每项 1–10 分。门槛见 `scripts/devloop/gates.json` 的 `judge`（默认：每项 ≥ 4，平均 ≥ 6，不退步 ≥ 6）。
评的是“比上一版更接近目标、且没退步”，不是要求一次做到与参考一致。
